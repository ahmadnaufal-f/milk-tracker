## Background

Currently, the AI summary button is conditionally rendered — it only appears when the user has more than 7 days of pumping data. The requested change is to **always show the button**, but disable it and show a tooltip explaining why it's unavailable when the condition is not met.

---

## Change Summary

| | Before | After |
|---|---|---|
| Has 7+ days of data | Button visible, active | Button visible, active |
| Has < 7 days of data | Button not rendered | Button visible, disabled + tooltip |
| Guest user (anonymous) | Button not rendered | Button visible, disabled + tooltip |

---

## Disabled Conditions

The button should be in a disabled state when **either** of the following is true:

1. User has fewer than 7 days of pumping data
2. User is an anonymous/guest user (no linked account)

Each condition should have its own tooltip message.

## Implementation Notes

1. **Remove the conditional render** that hides the button when data is insufficient — replace it with a disabled state instead

2. **Evaluate disabled conditions in order**:
   - Check `isAnonymous` first (guest user takes priority)
   - Then check if data spans fewer than 7 days

3. **Tooltip behavior**:
   - Tooltip should trigger on click (not hover) since the button is likely used on mobile
   - Dismiss on outside click or a close button within the tooltip
   - If the existing codebase already has a tooltip component, use that — don't introduce a new one

4. **Disabled styling**:
   - Reduced opacity or muted color to visually signal the inactive state
   - Cursor should indicate non-interactivity (`cursor: not-allowed` or equivalent)
   - Match the existing disabled button style convention in the codebase if one exists
