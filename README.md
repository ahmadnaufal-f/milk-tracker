# Milk Pump Tracker PWA

A progressive web application designed to help mothers track their pumping sessions, monitor milk volume, and maintain a history log.

## Features

*   **Pumping Timer**: Track duration and volume with a built-in timer.
*   **Offline Support**: Fully functional offline. Data syncs automatically when online.
*   **PWA Installable**: Install on your phone (Android/iOS) for a native app experience.
*   **History Log**: View daily and weekly pumping summaries.
*   **Secure**: Authentication and data storage using Firebase.

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    pnpm install
    ```
3.  Run development server:
    ```bash
    pnpm dev
    ```

## Build

To build for production:
```bash
pnpm build
```

## Tech Stack
*   React + Vite
*   TypeScript
*   Tailwind CSS
*   Firebase (Auth, Firestore, Hosting)
*   Vite PWA
